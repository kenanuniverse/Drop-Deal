# Drop-Deal

Drop Deal web mockup with Shop, Cart, Drop App, and Seller views, plus Turkish and English language options.

## Live Demo

[Open Drop Deal](https://kenanuniverse.github.io/Drop-Deal/)

GitHub Pages serves the root of the `main` branch. Pushing updates to `main` republishes the site.

## Local Preview

Open `index.html` directly, or run `python -m http.server 5174` from this directory and visit http://127.0.0.1:5174/.

This is a frontend demo. Product prices, competitor links, identity verification, and integrations are simulated. Demo data is stored in the browser's `localStorage`.
